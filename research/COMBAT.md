# Standing punch, kick and contact reconstruction

The ordinary standing punch and kick use handwritten JavaScript translations of the US rev 2 handlers. Their animation clocks, contact geometry, basic damage, ordinary hit reactions and sound-command output are connected to the match. Normal inside-ring knockdowns and ring correction now have separate translations in [knockdown research](KNOCKDOWNS.md). Grapples, other airborne paths and the remaining move selection are still open.

## Original paths

The standing fallback at `$00d6fa` selects move-table row zero. All twelve character tables selected through `$00d73e` have row `[0,114,255]`. The two individual buttons select action 0 and action `$72`. The combined-button entry leads to running state 2. Its descriptor `$010ea2` uses poses 9–14 with delay 6, and handler `$010ec2` loads the character running speed from `$010f8a`. That running path still needs translation. The prototype currently gives the second button priority for combined input and exposes its authored run through a separate control. Close-contact paired-state arbitration is a separate path beginning at `$00e7b4`.

Action 0 uses descriptor `$011a90` and handler `$011ac8`. It plays poses 0,146,147,148,147 with delay words 10,6,4,10,2. The handler chooses contact record 33, changing to record 7 while animation index 3 is active. Normal completion occurs on update 38 counting the entry as update zero.

Action `$72` uses descriptor `$019206` and handler `$01921a`. It plays poses 0,461,462 with delays 10,10,10. The handler chooses contact record 1, changing to record 17 on index 2. Normal completion occurs on update 34 counting the entry as update zero.

Actor updates load a contact record before advancing the animation. The pass at `$0232b6` then clears contact and the per-target hit mask whenever the pose word changes. Consequently the punch can first contact on update 24, and the kick on update 23. Successful hits mark that target in the attacker's per-pose hit mask. This prevents repeat damage while the same contact pose remains active.

The main frame path at `$000fe0-$000fec` runs actor updates, contact processing, then damage/combo-window service in that order. The JavaScript match now preserves that ordering for these paths. New damage reactions start their animation on the following update. Button actions use rising edges, matching the original input edge service, so holding a button does not repeatedly start attacks.

## Geometry and responses

| Address | Recovered role |
| --- | --- |
| `$023288` | Active actor contact dispatch |
| `$02334c` | Target eligibility and ground-distance gates |
| `$0233dc` | Per-pose target hit mask check |
| `$02340e` | Select attack/hurt rectangles, test optional second hurt rectangle |
| `$02348a` | Horizontal overlap, facing from pose words |
| `$023504` | Vertical overlap, using world height |
| `$02362e` | Punch hit response |
| `$023910` | Kick hit response |
| `$023a78` | Secondary response zero |
| `$023fa0`, `$023fde` | Facing-dependent reaction remapping |
| `$024012`, `$024028` | Successful contact cleanup |
| `$02407e` | Pending damage and combo timer service |
| `$02411c` | 34 seven-byte contact records |
| `$02420a`, `$024236` | Eleven attack rectangles and eleven hurt rectangles |

Contact byte zero contains attack flag `$80`, hurt flag `$40`, and second-hurt-rectangle flag `$20`. Bytes 1/2 select hurt rectangles, byte 3 selects the attack rectangle, byte 4 supplies damage, byte 5 selects the primary response, and byte 6 selects the secondary response.

The ground gate requires horizontal separation below 80 and depth separation below 12, using word coordinates. Target contact record 20 applies a depth offset of minus eight before that comparison. Horizontal mirroring uses bit 15 of the current pose word, while response remapping uses the current actor-facing field. The translation preserves the source's unsigned comparisons, signed byte offsets and endpoint tests, including unusual/reversed rectangles.

Normal punch contact record 7 deals one point and emits sound commands `$2a,$32`. Kick contact record 17 deals two points and emits `$2b`. These requests go through the translated native audio sequencers. The response increments a target's combo counter when its ordinary reaction begins and starts a 64-update window. Further hits can select the original airborne reaction once the pre-hit counter reaches three. The normal inside-ring airborne/down/get-up path is now translated and connected.

Ordinary punch reaction 0 uses descriptor `$01a2c0`, handler `$01a2d0`, poses 15/16 and delays 6/6. Ordinary kick reaction `$0a` uses descriptor `$01a612`, handler `$01a61e`, pose 16 and delay 16. Their normal completion takes sixteen and nineteen updates respectively, including entry and the completion-handler update.

## Verification and limitations

`tests/fixtures/combat-reference.json` is generated by executing original routines offline with the externally supplied analysis interpreter documented in [actor research](ACTORS.md). It covers:

- 184,960 rectangle cases and corresponding eligible ground-contact results across all 34 contact-record pairs, both actors' facing combinations, ten horizontal offsets and four height offsets.
- 36 depth-boundary cases, including the special offset for record 20.
- Complete punch and kick update handlers in both directions, followed by the original pose/contact cleanup pass.
- Both ordinary reaction handlers in both directions.
- 192 original hit-response cases covering facing, combo count and special contact/status flags, compared for acceptance, damage, reaction selection and sound commands.
- Six 100-update runs of the original actor dispatcher, pose cleanup, contact dispatch and damage service. The integrated JavaScript match produces identical pose words, contact IDs, ordinary state transitions, health changes, combo counters/timers and sound output for single standing attacks at hit/miss distances 40,70,80.

Browser checks additionally exercised both actions through a simulated standard gamepad, verified the visible punch/kick poses, one/two-point damage and exact routed sound commands, and found no page errors. Physical controller testing is still pending.

The bounded standing-attack fixtures bypass world-boundary correction to isolate those handlers. Inside-ring collision and the punch entry nudge now use the separate translated ring routine, with broader controlled-input integration runs described in [knockdown research](KNOCKDOWNS.md). The alternate status-dependent punch descriptor, combined-button running, paired-state arbitration, other move rows, original actor health initialization, AI and match rules remain incomplete. Health still uses the practice prototype's 100-point maximum. Full combat parity is not claimed.

Regenerate the fixture from a separately interleaved original program image:

```sh
node tools/trace_combat.mjs path/to/mc68000.js path/to/program.bin tests/fixtures/combat-reference.json
npm run check
```

CPU execution is confined to offline research. Browser delivery contains recovered tables and translated JavaScript actor/audio functions.
