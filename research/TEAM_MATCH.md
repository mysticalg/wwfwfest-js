# Four-person native tag playtest

Version 0.1.25 switches the page from the earlier two-person practice adapter
to four stable native actor records in slots 0, 1, 4 and 5. Lead/opponent/
assistance pointers, role bits and controller ports remain distinct. Physical
records never swap when the player tags. Human teammates share the original
input port and button history; the lead/control flags select the new wrestler.

Select both teammates on the page. With a standard pad, hold either shoulder
while using menu directions to change the partners. Walk to the home corner,
wait for the apron partner, then press punch or kick. The default playtest uses
recovered human selection and computer movement decisions for all four records.
Turning off the computer opponent retains the player's apron partner brain.

## Composed original-program comparison

`trace_team_match.mjs` seeds explicit synthetic neutral four-record starting
states, then executes the original camera, target service, grapple arbitration,
tag timers, announcer queue, human input, AI, referee, actor dispatcher,
collision/projection/physics, alternating contact/damage and sprite queues.
The native `Match` replays the same input and observed random values.

**12 sequences / 4,582 updates** match all captured actor fields and links,
clocks, projected positions, world requests, announcer state, camera, referee,
effects and sound-command order. Neutral, approach/attack, running and manual
tag profiles use player types 0, 7 and 10. Ten reach the 400-update cap; two
approach cases stop before the unimplemented action 8 on update 290. Those
boundaries are asserted. The trace preserves the partial earlier actor updates
on the boundary phase rather than inventing an unsupported continuation.

These comparisons exposed and fixed the human selector's word/byte gate and
secondary-target write, the contact `$92` alias used by counter flight/action 6,
apron timer maintenance, and the missing name/move announcer service. They do
not cover full round initialization, original hardware input sampling, title/
scene bookkeeping, moving effect objects or complete ambient RNG register
context. Starting positions are playtest choices, not a recovered round intro.

## Rendering and sound

The original sprite queues draw modes 5 through 0, sorting signed world Y in
modes 5, 4, 2 and 0 with stable ties. Referee enqueue precedes the physical
actor loop. Projection/enqueue occurs before physics, and unlink cleanup runs
after contacts only on queued visible records. A further **512 original-program
queue cases** cover sorting, clipping, hidden poses and stable ties. The moving
320-pixel viewport can leave a far apron partner offscreen, as in the source.
The current team HUD is provisional Canvas text and health bars.

`announcer.js` translates `$009ba8/$009ecc`, including name eligibility,
phrase sequencing, request consumption and original delays. The name and
46 phrase tables are editable, regenerated by `extract_announcer.py`. Native
audio playback uses the existing recovered score/effect sequencers; listening
acceptance and all later scene requests remain unverified.

A separate original-program comparison covers **104 announcer scenarios /
9,882 service calls**: all 46 phrase entries, all 24 name entries with both
lead and bench eligibility, and ten interrupted requests. This checks command
and delay routing, rather than the acoustic output of the synthesizer.

## Browser verification and remaining work

A simulated standard controller selected teammates, started the default match,
walked to the corner, tagged to DiBiase, moved him, paused/resumed, completed a
controlled cover with count sounds 98/99/100, and started a four-person rematch.
Native audio was enabled, CPU AI was off for that controlled tag/cover test,
and there were no page errors. A 390-pixel viewport had no horizontal overflow.
Physical pads and human listening remain unverified.

This remains an early playtest. Untranslated actions can stop an ordinary
match; original round/result progression, remaining holds/escapes and airborne
actions, outside-ring combat, Royal Rumble, moving ropes/effects, original HUD
and complete gameplay/audio parity remain unfinished. No CPU emulator runs in
the browser.
