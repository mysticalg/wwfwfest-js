# Native actor movement and animation

This milestone translates the ordinary idle/walk path and the generic movement and descriptor-clock routines from the supplied US rev 2 program. The browser runs editable JavaScript functions. Offline CPU execution supplies comparison fixtures.

## Original locations

| Program address | Role |
| --- | --- |
| `$002218` | Movement-mode dispatcher |
| `$00223c` | Polar movement, low byte of speed and direction |
| `$002262` | Signed velocity movement and gravity |
| `$0022d0` | Quadrant selection and fixed-point displacement |
| `$002388`, `$00240a` | 65-word horizontal/depth tables |
| `$00e516` | Direction word for each four-bit directional input mask |
| `$00fe28` | Face the linked opponent, with action-dependent target offsets |
| `$0106ec`, `$0106f2` | Idle descriptor and update handler |
| `$010832`, `$01084a` | Ordinary/alternate walk descriptors |
| `$010862`, `$01087a` | Two status-dependent walk descriptors |
| `$010892` | Walk substate dispatch |
| `$0108ee`, `$0108fa` | Twelve character speeds for ordinary/alternate walking |
| `$010906` | Ordinary walk update handler |
| `$010950`, `$01098c` | Walk descriptor and speed selection |
| `$01b27e` | Actor update/animation dispatcher |
| `$01b308` | Generic animation clock |

The actor record stores mode at byte `$01`, type at word `$02`, pose at word `$04`, signed 16.16 position longs at `$06/$0a/$0e`, animation flags at `$1c`, remaining delay at `$22`, frame index at `$24`, speed/direction at `$2a/$2c`, facing XOR at `$2e`, velocity words at `$58/$5a/$5c`, and gravity at `$5e`.

Descriptors contain an update-function pointer, a mode word, a count word, count delay words, and count pose words. Delay 10 lasts eleven calls because advancement happens on unsigned underflow. `$ff00` holds indefinitely. Mode 2 loops. Other nonzero modes finish with index `$fe`, delay zero, and the last pose retained. Mode zero leaves the clock untouched. Facing is XORed into a pose only when a frame loads.

Ordinary walking uses poses 1–4, each with delay 10. The ordinary idle handler sets its own initialized bit. On entry it clears the counters and retains the previous pose for one frame. Later calls select pose zero with the current facing. Walking faces the linked opponent even when moving away. The delivered normal-opponent path follows this behavior. Action-dependent target offsets await combat reconstruction.

The twelve ordinary speed bytes are 27, 29, 28, 25, 30, 27, 24, 30, 22, 27, 28, 27. The polar tables have maxima 5120 horizontally and 4096 in depth, in 16.16 units before multiplication by speed. Hogan's horizontal walk displacement is therefore 2.109375 pixels per logical update. Diagonal values come directly from the tables.

Movement mode 2 adds signed 8.8 velocity words to the position longs and subtracts gravity from the vertical velocity with word wrap. The source's apparent negative-velocity clamp is unreachable under its unsigned comparison. The translation preserves that behavior. This primitive is verified for future airborne-action work and is not yet connected to match jumps or throws.

## Verification

`tests/fixtures/actors-reference.json` was generated by running original routines with an externally supplied offline 68000 interpreter. It stores results/hashes, not CPU code. The production test suite compares:

- All 65,536 combinations of direction byte and speed byte against `$0022d0`.
- 1,024 seeded movement scenarios, each sixteen updates, including signed positions, both movement modes, gravity and wrap.
- 384 character/status combinations against the original speed and descriptor-selection routines.
- 51 animation scenarios, including eleven recovered descriptors, finite completion, looping, facing changes, zero mode, held frames and counter boundaries.
- Four idle-entry scenarios through the complete original actor dispatcher.
- Twelve character locomotion runs through the original idle/walk update handlers, animation dispatcher and movement routine. Each runs 120 updates with starts, eight directions, reversals and stopping. The integrated JavaScript match produces the same positions and pose words in this bounded ordinary context.

These checks establish the translated paths within the stated inputs. They do not establish full-match equivalence, ring collisions, combat, tag rules, Royal Rumble, camera behavior or physical controller acceptance. Arena constraints, running, attacks, hit checks, damage, recovery, AI and pinning remain provisional. Other animation descriptors in the fixture verify the generic clock, not their complete action handlers.

Reproduce data extraction from the archive:

```sh
python tools/extract_actors.py path/to/wwfwfest.zip
```

Regenerate original comparison fixtures after interleaving IC18/IC19 into a program image. Supply the external analysis interpreter separately:

```sh
node tools/trace_actors.mjs path/to/mc68000.js path/to/program.bin tests/fixtures/actors-reference.json
npm run check
```

The analysis interpreter came from [iapx86's hardware project](https://github.com/iapx86/JavaScript), revision `9ca520534893f4348274aa24b979d99697f3102d`. It is excluded from this repository and the browser runtime.

## Next action paths

The ordinary standing-button fallback at `$00d6fa` returns move-table row zero. `$00d1d6` selects a three-byte row from each character's table, whose pointer table begins at `$00d73e`. Row zero is `[0,114,255]` for all twelve types. Action zero points through `$011854` to descriptor `$011a90` and handler `$011ac8`. The descriptor's poses are 0,146,147,148,147 with delays 10,6,4,10,2. The handler selects contact record `$21`, switching to `$07` on animation index 3, and handles completion at index `$fe`. Collision handling and contact-record interpretation still need translation before this action replaces a prototype attack.
